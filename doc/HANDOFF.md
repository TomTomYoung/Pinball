## 1. 再開地点

P-01～P-07の基礎修正、および背景・部品・UI・効果音・BGMの本体組込みは実装済みです。[SPECIFICATION.md](./SPECIFICATION.md)が現行仕様、[STATUS.md](./STATUS.md)が検証と残課題です。修正前の文書はhistoryに保存しており、未修正の記載を現行状態と取り違えないでください。

利用者はindex.htmlを直接開きます。npmや開発サーバーの手動起動を必須にする構成へ変更しないでください。画像・音声はデータURLで内包し、実行時の外部依存はPhaser CDNだけです。package.jsonは開発時の再生成・テスト用です。backup・backup2、別リポジトリpinball2は変更対象ではありません。

編集する原稿は`src/index.template.html`と`src/media.js`です。`python tools/build-game.py`でindex.htmlを再生成し、原稿と生成物を一緒にコミットします。配布用index.htmlを直接編集すると再生成で失われます。素材を変更した場合は先に`python tools/build-asset-catalog.py`でハッシュ付き台帳を更新します。

## 2. 維持する条件

- constructorの途中で未初期化の派生メソッドから描画・物理を作らない。
- 編集モデルを正本とし、描画と物理へ同じ寸法・角度・色を反映する。displayWidth変更とBody.scaleを併用しない。
- 円は半径を正本とする。縦横別々に拡縮しない。
- 外周の用途はisBoundaryで管理する。名前で編集可否を判定しない。
- EditorSceneは物理停止、プレイ中はsleepして非表示。プレイ用は編集データから別に生成する。
- GameScene.initで全プレイ状態を初期化する。終了後は物理・入力・加点を止める。
- ScenePlugin経由でstart／restart／stopする。PhaserのshutdownではMatterPlugin.worldが先にnullになる順序にも対応する。
- 読込は全検証・仮生成が完了してから置換する。失敗時は旧盤面・選択を保持する。
- WebGLのテクスチャ／描画バッファ上限を超える盤面は仮生成より前に拒否する。後からsetGameSizeで失敗させない。
- resizeでは表示だけを同比率で変え、盤面座標はboardに保持する。
- 素材描画のContainerをMatterボディにしない。既存Shapeを物理の正本とし、postupdateで描画だけ同期する。
- スキン非対応の色・縦横比・極端な寸法はShapeで表示する。素材に合わせて編集値を上書きしない。
- 再プレイでテクスチャを増やさず、各シーンのContainer・演出・postupdateリスナーを破棄する。
- 音源を停止した後、古い非同期デコード完了から再開させない。音声の世代番号を維持する。
- 旧データの内容を推測で削除しない。外周候補の置換には画面上で選択肢を出し、旧文字列も保全する。

## 3. 2026-10-16に決めた仕様

新規盤面800×1000、保存schemaVersion=1、反発係数0～2、得点0と角度0を許可します。旧データに盤面寸法がないため、旧外周の完全一致候補から復元できる場合のみそのサイズを採用し、それ以外は現在の盤面サイズを使用します。

フリッパーは支点座標を保持し、描画と物理の中央を揃えた動的ボディ＋worldConstraintで実装します。目標角へ角速度で駆動し、キーを離すと初期角度へ戻します。3.60.0同梱MatterではignoreGravityだけでは重力が消えないため、beforeupdateで対象ボディの重力を相殺しています。Phaser更新時はこの条件とtests/harness.cjsのライブラリ読込方式を見直してください。

開始位置の半径・色・反発・摩擦を実ボールへ反映するようにしました。既定値は従来どおり半径10、白、反発0.8、摩擦0.005です。マーカーなしの開始座標は毎回盤面の幅/2・高さ/3へ戻します。

## 4. 必須の回帰確認

```sh
npm ci
python tools/build-game.py
npm test
npx playwright install chromium
npm run test:browser
npm run test:media
```

engine.test.cjsは実Phaser/Matterを使う14件、browser.test.cjsは実ブラウザ8件、media.test.cjsは素材・音声の本体組込み6件です。通常のブラウザテストは自動で一時サーバーを起動します。素材組込みテストはHTMLだけを別の一時フォルダへコピーし、file://で起動して追加ファイルが不要であることも検証します。Chrome実行ファイルを別途提供する環境ではPINBALL_BROWSER_EXECUTABLEを指定します。

手動確認では以下を通します。

1. 初回起動に例外がなく、外周3枚が静止し、一覧には外周が出ない。
2. 壁、バンパー、左右フリッパー、開始位置を追加する。色・半径・角度を変え、寸法変更後に繰り返しドラッグしても物理形状が一致する。
3. 保存→ページ再読込→読込で全値が一致し、外周が増えない。
4. 左矢印／Z、右矢印／スラッシュで操作でき、バンパー得点と0点設定が反映される。
5. 落下終了→もう一度を4回以上繰り返す。得点0、一定の物体数、終了後の停止を確認する。
6. 両方の編集復帰ボタンで戻り、終了表示が消えて元の盤面を再編集できる。開始位置を消した再プレイが既定位置になる。
7. ウィンドウ縮小後も同比率で、長い壁の端を選択・ドラッグできる。
8. 不正JSON、objects欠落、未知type、負の寸法、読込途中例外、容量不足で旧盤面を失わない。
9. 旧形式の外周置換を承認／キャンセルし、同名ユーザー壁と旧文字列の保全を確認する。
10. 素材付きの物体の色・寸法を変更し、Shapeへの切替と戻りを確認する。球・回転中フリッパーの描画が実ボディに追従することを確認する。
11. 起動時は無音、操作後は効果音・BGMが鳴ること、ミュート・独立音量、終了・編集復帰・タブ非表示での停止を確認する。再プレイ4回で音源・テクスチャ・リスナーが増えないことを確認する。

### 素材制作順（2026-10-16 全10分類の制作・検証完了）

1. 盤面背景: 800×1000の盤面に対応。可動部品・壁・文字を焼き込まない背景。画像生成で制作し、同比率で表示する。
2. 筐体・外周枠: 直線と角の独立部品。辺を反復し、角を固定寸法で組み立てる。底辺は装飾であり、物理的な床ではない。
3. 壁・レール: 継ぎ目のない本体と左右端部。長さは本体の反復／クリップで調整し、引き伸ばさない。
4. ボール: 球体と影を別素材で用意。真円・透明背景。既定半径10への同比率縮小を想定する。
5. フリッパー: 左右の本体、支点キャップ。現行の矩形ボディと端の支点に対応し、左右を鏡像で用意する。
6. バンパー: 台座・通常・点灯・発光を分離。真円と透明背景を維持する。
7. 衝突演出: 火花・リングなど、短いアニメーション用の独立フレーム。
8. UI: スコア枠、通常／押下ボタン、編集アイコン。文字と数値は素材に焼き込まず、実際のDOMテキストで表示する。
9. 効果音: 弱／強の壁衝突、バンパー、フリッパー上げ／戻し、落球、開始、終了、UIの計9種。外部録音を使わず合成し、短いWAVとして用意する。
10. BGM: 低優先度のループ1曲。効果音と別音量にできる構成、ループ境界と波形ピークを確認する。

### 素材の共通条件

- 保存先は`assets/`。寸法・原点・支点・用途・制作方法・使用条件を素材台帳に記録する。
- 現行の青いバンパー、赤いフリッパー、銀色の壁・白い球を基調に統一する。
- 精密な部品・UIは編集可能なSVG。画像生成した背景は完成画像とプロンプトを保持する。
- 背景の外側に部品を描き込まない。影・発光を当たり判定に含めない。

- index.htmlを直接開く利用方法、保存形式、物理パラメータは維持する。
- 制作完了とゲームへの組込み完了を混同せず、完了素材・検証結果・残工程を本書とSTATUSに追記する。
