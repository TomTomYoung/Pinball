## 1. 再開地点

利用者はindex.htmlを直接開きます。npmや開発サーバーの手動起動を必須にする構成へ変更しないでください。package.jsonは開発テスト専用です。backup・backup2、別リポジトリpinball2は変更対象ではありません。

## 2. 維持する条件

- constructorの途中で未初期化の派生メソッドから描画・物理を作らない。
- 編集モデルを正本とし、描画と物理へ同じ寸法・角度・色を反映する。displayWidth変更とBody.scaleを併用しない。
- 円は半径を正本とする。縦横別々に拡縮しない。
- 外周の用途はisBoundaryで管理する。名前で編集可否を判定しない。
- EditorSceneは物理停止、プレイ中はsleepして非表示。プレイ用は編集データから別に生成する。
- GameScene.initで全プレイ状態を初期化する。終了後は物理・入力・加点を止める。
- ScenePlugin経由でstart／restart／stopする。PhaserのshutdownではMatterPlugin.worldが先にnullになる順序にも対応する。
- 読込は全検証・仮生成が完了してから置換する。失敗時は旧盤面・選択を保持する。
- resizeでは表示だけを同比率で変え、盤面座標はboardに保持する。
- 旧データの内容を推測で削除しない。外周候補の置換には画面上で選択肢を出し、旧文字列も保全する。

## 3. 2026-10-16に決めた仕様

新規盤面800×1000、保存schemaVersion=1、反発係数0～2、得点0と角度0を許可します。旧データに盤面寸法がないため、旧外周の完全一致候補から復元できる場合のみそのサイズを採用し、それ以外は現在の盤面サイズを使用します。

フリッパーは支点座標を保持し、描画と物理の中央を揃えた動的ボディ＋worldConstraintで実装します。目標角へ角速度で駆動し、キーを離すと初期角度へ戻します。3.60.0同梱MatterではignoreGravityだけでは重力が消えないため、beforeupdateで対象ボディの重力を相殺しています。Phaser更新時はこの条件とtests/harness.cjsのライブラリ読込方式を見直してください。

開始位置の半径・色・反発・摩擦を実ボールへ反映するようにしました。既定値は従来どおり半径10、白、反発0.8、摩擦0.005です。マーカーなしの開始座標は毎回盤面の幅/2・高さ/3へ戻します。

## 4. 必須の回帰確認

```sh
npm ci
npm test
npx playwright install chromium
npm run test:browser
```

engine.test.cjsは実Phaser/Matterを使う14件、browser.test.cjsは実ブラウザ8件です。ブラウザテストは自動で一時サーバーを起動します。Chrome実行ファイルを別途提供する環境ではPINBALL_BROWSER_EXECUTABLEを指定します。

手動確認では以下を通します。

1. 初回起動に例外がなく、外周3枚が静止し、一覧には外周が出ない。
2. 壁、バンパー、左右フリッパー、開始位置を追加する。色・半径・角度を変え、寸法変更後に繰り返しドラッグしても物理形状が一致する。
3. 保存→ページ再読込→読込で全値が一致し、外周が増えない。
4. 左矢印／Z、右矢印／スラッシュで操作でき、バンパー得点と0点設定が反映される。
5. 落下終了→もう一度を4回以上繰り返す。得点0、一定の物体数、終了後の停止を確認する。
6. 両方の編集復帰ボタンで戻り、終了表示が消えて元の盤面を再編集できる。開始位置を消した再プレイが既定位置になる。
7. ウィンドウ縮小後も同比率で、長い壁の端を選択・ドラッグできる。
8. 不正JSON、objects欠落、未知type、負の寸法、読込途中例外、容量不足で旧盤面を失わない。
9. 旧形式の外周置換を承認／キャンセルし、同名ユーザー壁と旧文字列の保全を確認する。
