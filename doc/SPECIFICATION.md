# Pinball 現行仕様

更新日: 2026-10-16 JST  
修正開始基準: main / `482d8613a2c2494c68c27b9618805509a9b076c8`

## 1. 構成と依存

HTML・CSS・JavaScriptは[index.html](../index.html)に同梱しています。実行時の外部依存はCDNから読むPhaser 3.60.0のみです。物理は同梱Matter、重力はy=1、debug=false、描画はPhaser.AUTOです。画像・音声・バックエンド・ビルドは不要です。

別途、組込み前の画像・SVG・音声49点を`assets/`に用意しています。素材の仕様は[assets/README.md](../assets/README.md)、寸法・支点は[manifest.json](../assets/manifest.json)を参照してください。`assets/index.html`は素材確認専用で、本体の描画・音声・保存動作はまだ変更していません。

主な責務は次のとおりです。

- `LayoutCodec`: 保存データ・編集入力の検証と正規化、旧外周壁の候補判定。
- `PinballGame`: アプリの状態、DOMボタン、ScenePluginを通じたシーン遷移、表示サイズ。
- `GameObject`と4派生クラス: 編集データ、描画・物理への反映、選択判定、シリアライズ。
- `EditorScene`: 配置、選択、ドラッグ、プロパティ編集、保存と読込。
- `GameScene`: レイアウトの複製、実ボール生成、フリッパー駆動、衝突加点、終了。

基底constructorは描画を生成しません。派生側で半径・固定状態・色などを設定し終えてから生成します。

## 2. 盤面と画面サイズ

新規盤面の論理座標は800×1000です。保存データの`board.width`・`board.height`が盤面の正本で、外周、開始位置の既定値、落下判定もこれを使用します。読込時に保存盤面のサイズへ切り替わります。盤面寸法を変更するUIはまだありません。

`Phaser.Scale.FIT`と`CENTER_BOTH`で、左の描画領域へ縦横同比率で収めます。ウィンドウresize・ペインサイズ変更では座標・寸法・ボディを変更しません。横幅720px以下では描画領域を上60%、プロパティを下40%へ配置します。フリッパーのタッチ用操作ボタンはありません。

左・右・上に厚さ10の固定外周を生成し、下には床を作りません。外周は`type: 'wall'`と`isBoundary: true`を持ちます。isBoundaryは用途の属性で、物体種別と分離します。外周は選択・一覧・削除・保存の対象外です。通常の壁に「左壁」と名付けても外周にはなりません。

## 3. エディター

起動時は外周3枚のみです。EditorSceneのMatter Worldは停止し、編集している物体が重力で動くことはありません。

追加時の値は次のとおりです。

- 壁: (200,200)、100×20。
- バンパー: (200,200)、半径20。
- フリッパー: 支点(150,盤面高さ−100)、100×20、左向け。
- 開始位置: (200,200)、半径10。既存の開始位置がある場合はその位置を戻して選択し、マーカーを複数にしません。

選択は表示形状に合わせた円・回転矩形の判定です。重なる場合は後から配置したものを優先します。選択中は黄色の枠線を表示し、ドラッグではクリックした位置と物体位置の差を保持します。フリッパーのX・Yは支点座標です。ポインターを外で離した場合もドラッグを終了します。

編集項目は名前、位置、反発係数、色に加え、壁は幅・高さ・角度、円形物体は半径、バンパーは得点、フリッパーは幅・高さ・初期角度・フリップ角度・左右、開始位置は摩擦係数です。円形物体の幅と高さは半径の2倍へ揃え、別々には編集しません。フリッパーの左右を変更すると、初期角度とフリップ角度の符号も反転します。

数値は有限値を検証し、無効な入力では元の値を保持して画面へ通知します。寸法は1～10000、半径は0.5～5000、角度は−180～180度、反発は0～2、得点は0～1000000、摩擦は0～1、座標は−100000～100000です。名前は200文字まで、色は`#RRGGBB`です。ドラッグで設定する位置・支点は盤面内に収めます。0の得点・反発・角度を保持します。

## 4. 描画と物理

編集データを正本とします。矩形は描画の内部サイズを変更し、寸法が変わった時だけMatterボディを正しい寸法で再生成します。円は描画半径と物理半径を同じ値にします。移動・色・名前の変更に累積scaleは使用しません。色はShapeの`setFillStyle`で更新します。

### Wall

矩形です。isStaticの既定値はtrue、反発は0.7、色は#888888です。旧データのisStatic=falseも保持しますが、編集中はWorld自体を停止します。isStaticを切り替えるUIは現行にありません。

### Bumper

静的な円で、反発1.5、得点50、色#00aaffが既定です。実ボールとのcollisionstartで指定得点を加算し、100ms黄色に光ります。得点0なら加算しません。連続衝突時は前のフラッシュタイマーを置き換えます。

### Flipper

矩形で、色#ff0000、反発0.8です。支点X・Y、幅・高さ、左右、初期角度、フリップ角度を保存します。左の既定角度は0→−45度、右指定で生成した場合は0→+45度です。

描画原点は物理と同じ中央です。左は支点から右へ、右は支点から左へ半幅進んだ場所をボディ中心とし、端の支点を`worldConstraint`で固定します。編集時は静的、プレイ時は動的ボディです。beforeupdateで押下状態に応じた目標角へ角速度を設定します。最大角速度0.25rad/step、誤差への係数0.45、frictionAir=0.05、density=0.01、ヒンジstiffness=1・damping=0.2です。

3.60.0同梱MatterのEngineはignoreGravityを参照しないため、フリッパーにかかる重力をbeforeupdateで明示的に相殺します。球との衝突は動くボディに対して計算され、角度の瞬間切替ではありません。機械式の角度ストッパーは未実装で、目標角の保持は駆動処理が行います。

### Ballと開始位置

開始位置マーカーは物理ボディなし、alpha=0.5です。実ボールの既定値は半径10、反発0.8、friction=0.005、frictionAir=0.001、白です。開始位置マーカーがある場合は位置・半径・色・反発・摩擦を実ボールへ引き継ぎます。

マーカーがない時は盤面の(幅/2, 高さ/3)から始めます。前回の開始位置は引き継ぎません。初速度Xは`Math.random()*4-2`、Yは−5です。発射ボタンやseed指定はありません。

## 5. プレイと終了

アプリ状態はloading→edit→starting→play→overで、編集復帰はreturningを経由します。ロード完了前や遷移中の操作を無効化します。EditorSceneはsleepして非表示にし、GameSceneへ編集データのコピーを渡します。編集中の物体をプレイ用に流用しません。プロパティパネルはプレイ中inertです。

左矢印またはZで左、右矢印またはスラッシュで右を操作します。スラッシュのPhaserキー名は`FORWARD_SLASH`です。動作中フリッパーとの衝突は10点、バンパーは指定点です。

ボール中心が盤面高さ＋ボール半径＋50より下へ落ちると、一回だけ終了します。isGameOverを立て、World・キーボードを停止し、以後の更新・加点を拒否します。「もう一度」はGameScene自身のScenePlugin.restartを使用します。initでscore、objects、ball、終了状態を毎回初期化し、shutdownで自前の参照・タイマー・ヒンジを破棄します。

「エディターに戻る」「エディットに戻る」は同じ復帰処理を通り、GameSceneを停止、EditorSceneをwakeし、終了オーバーレイも消します。リプレイに前回のスコア・破棄済み物体・開始位置は残りません。

## 6. 保存と旧データ

localStorageの`pinballLayout`一枠へ手動保存します。自動ロード、ファイル入出力、複数スロットはありません。

```json
{
  "schemaVersion": 1,
  "board": { "width": 800, "height": 1000 },
  "objects": [
    {
      "type": "wall", "x": 200, "y": 200,
      "width": 100, "height": 20, "angle": 0,
      "name": "Wall", "restitution": 0.7,
      "color": "#888888", "isStatic": true
    }
  ]
}
```

全物体はtype・x・y・width・height・angle・name・restitution・colorを保存します。壁はisStatic、バンパーはradius・score、フリッパーはisLeft・restAngle・flipAngle、開始位置はradius・friction・isBallPositionMarker=trueを追加します。外周、選択状態、スコア、速度、ヒンジは保存しません。

盤面寸法は200～10000、物体は1000個までです。未知type、不正構造・数値、未知schemaVersion、複数の開始位置、プレイ用ボールを含むレイアウトは拒否します。

読込は全レコードの検証後、仮の物体群を生成します。途中失敗時は仮の物体だけを破棄し、元の物体・選択を保持します。成功した時だけ一括置換します。保存容量不足、アクセス失敗も画面へ通知します。

schemaVersionのない旧形式も読めます。先頭3枚が旧コードの自動生成外周と名前・座標・寸法・固定状態・角度まで一致する場合のみ、外周候補として確認画面を表示します。承認した場合は3枚を固定外周へ置換し、キャンセルなら通常壁として保持します。同名という理由だけでは消しません。候補から旧盤面サイズを復元し、候補がなければ現在の盤面サイズを使用します。旧データ自体には盤面サイズがないため、後者は元のサイズを厳密に復元できません。

旧形式の保存文字列を新形式で上書きする前に、`pinballLayoutLegacyBackup`が未作成なら旧文字列をそのまま保全します。読込だけでは保存文字列を更新しません。
