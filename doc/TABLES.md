# 20台の遊び方

更新日: 2026-10-17 JST

index.htmlを開き、「この台で遊ぶ」を押すと開始します。1ゲーム3球です。Space / Enter / 発射ボタンで発射し、左は← / Z、右は→ / スラッシュ。画面下の左右ボタンは同時タッチに対応します。Q / 揺らすは2秒間隔で使えます。

バンパーの得点と、押下中（上げ切って保持中も含む）のフリッパーへの衝突10点を積み上げます。全バンパーに一度ずつ当てると1ゲームにつき一度だけ+1,000点。完成台の標準スキンでは、ヒット済みバンパーは点灯を保ちます。目標を超えても最後の球まで遊べます。終了時に台別BESTを保存します。

1. **クラシック・トライアングル**（入門／目標2,000点）: 3基のバンパーを三角に配置。左右100点、下中央150点です。広い打ち返しエリアから上部を狙う基本台です。
2. **カスケード**（初級／目標2,500点）: 段違いの3本の斜めレールと4基のバンパー。落ちる球の進路が左右へ変わります。レール端から落ちる位置を見て待ち受けます。
3. **オービット**（初級／目標3,500点）: 120点の6基を環状に配置。中央へ入れる打ち方と外側を回す打ち方で反射が変わります。
4. **ツインタワー**（中級／目標3,500点）: 左右に3基ずつの塔。各150点です。中央通路から左右に振り分けて、両側のヒットを揃えます。
5. **ダイヤモンド**（中級／目標4,500点）: 中央の大型300点バンパーを4基の120点バンパーで囲みます。中央と周辺を往復してボーナスを狙います。
6. **クロスファイア**（中級／目標4,500点）: 上下2組、計4本のフリッパー。上段に3基、下段に1基のバンパーを配置します。同じ側の上下フリッパーは一つのキーで連動します。
7. **スラローム**（中級／目標3,000点）: 大きなバンパーが左右交互に4基。蛇行しながら落ちる球を見て、最後の反射に合わせます。
8. **バンクショット**（上級／目標4,000点）: 2本の長い斜めレールと、左右奥の400点バンパー。中央は100点・150点です。レールの反射と外側の通路を利用して高得点を狙います。
9. **ピン・フォレスト**（上級／目標6,000点）: 小さな80点バンパー15基の密集配置。細かい連打と全15基の点灯を狙います。
10. **ラスト・ゲート**（上級／目標3,000点）: 支点間310、長さ110のフリッパーで、他の台より中央の隙間が広い構成。4基のバンパーは200・200・250・300点です。

「新機能10台」で以下の追加台だけを表示できます。分裂球・散弾はすべて同じラウンドで、全球の消失後に次の1球へ進みます。捕獲中と吸収後の再発射待ちもラウンドを継続します。

11. **アクセル・サーキット**: BOOSTで加速、SLOWで減速、TURNで左上へ旋回します。
12. **ミラー・ダンス**: 回転、直線往復、波形運動する反射板。REFLECTは球を上へ返します。
13. **マグネット・ハーバー**: 吸引・反発磁場とHOLD。捕獲後に自動で球を解放します。
14. **ワープ・リンク**: 同じ色の入口・出口が対です。転送直後の再転送は抑止します。
15. **ブレイク・ガーデン**: 耐久20／30の壁を通常球で2～3回当てて壊します。下側のVOIDに触れると球を失います。
16. **プリズム・スプリット**: 親球を3球へ分裂。球同士も反射します。子球の寿命は12秒です。
17. **リサイクル・リアクター**: 球を吸収し、0.65秒後に3球を再発射します。
18. **チャージ・ランチャー**: 捕獲中にE／特殊を長押しして離すと発射。短い連打でも充填できます。無操作でも6秒で自動発射します。
19. **チャージ・スウィング**: 左右を押して溜め、離して振ります。約0.8秒で満充填。強い打球で耐久付きターゲットを狙います。
20. **エクステンド・バースト**: 押している側のフリッパーが伸び、打ち返すと散弾を追加。左→右→E／特殊を1.4秒以内に押すと6秒間強化します。

終了画面の「もう一度」で同じ台、「次の台へ」で次の台、「台を選び直す」で一覧へ戻れます。20台目の次は1台目です。途中で台選択やエディターへ戻る場合、そのゲームの得点はBESTへ保存しません。

編集画面は「エディターを開く」から使用します。完成台を遊んでも作成中の盤面や保存データは置き換わりません。編集した盤面のテストプレイは1ラウンド（分裂・追加弾を含む）で、完成台の3球ルールとは別です。

台を構成する部品の図・設定値・台別個数は[オブジェクトカタログ](./OBJECT_CATALOG.md)にまとめています。

台の正本はsrc/tables.js（定番）とsrc/lab-tables.js（新機能）です。狙い方と目標点は初回の設計値であり、人による長時間の難易度調整は今後の対象です。
