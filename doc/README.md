## 現在地

Phaser 3.60.0とMatterを使う、単一HTMLの30台のピンボールと盤面エディターです。壁・バンパー・左右フリッパー・ボール開始位置・仕掛けを配置し、保存・読込・プレイ・再プレイ・編集復帰を行えます。

2026-10-16の精査で判明した初期化順、累積するボディ拡縮、外周壁の混入、再プレイ時の古い参照、読込失敗による盤面消失を修正しました。フリッパーは固定支点のヒンジと角速度で駆動します。実ブラウザでの再プレイ4回と保存往復を含む回帰テストを追加しました。その後、2026-10-17に10台を選んで遊べるアーケードを追加しました。各台は3球制、発射待ち、全バンパーボーナス、目標スコア、台別BESTを持ちます。

背景、金属レール、球、フリッパー、バンパー、衝突演出、UIと、効果音9種・BGM1曲を本体へ組み込みました。画像と音はHTMLへ内包しています。起動時は無音で、操作後に音が有効になります。上部のミュート・音量で調整できます。任意の色や素材に合わない縦横比は従来の図形で表示し、編集値と当たり判定を維持します。

共通Entityモデルによる基本19種類の仕掛けプリセットと、新機能を試す10台を追加しました。加速・吸引・反射・ワープ・破壊・分裂・吸収再発射・チャージ発射、チャージ／伸長／散弾フリッパーを組み合わせられます。台選択の「新機能10台」で追加分へ絞り込めます。

巨大化、通常＋強打・爆裂・電撃・貫通の5弾種、8種の敵、出現装置、ピストン・ばね台・重力クレートを追加しました。仕掛けは合計37プリセットです。「アクション10台」で追加台へ絞れます。敵の撃破条件・行動とJSON記法は[ACTION_MODEL.md](./ACTION_MODEL.md)にあります。上部「音・演出」で演出を軽減できます。

## 30台で遊ぶ

起動後の台選択画面で「この台で遊ぶ」を押します。Space / Enter / 発射ボタンで1球ずつ開始し、左は← / Z、右は→ / スラッシュです。画面下の左右ボタンは同時タッチにも対応します。Q / 揺らすボタンは2秒間隔で使用できます。

特殊操作はEまたは画面下の「特殊」ボタンです。発射台は長押しして離すと発射、短い連打で充填します。チャージフリッパーは左右を押して溜め、離して振ります。分裂しても全ての球を失うまで次の球には進みません。

全バンパーに当てると1ゲームに一度だけ+1,000点。3球での合計と台別BESTを競います。ただし防衛台では、突撃兵がDANGERへ入ると残球に関係なく終了します。終了画面から再挑戦・次の台・台選択へ進めます。台一覧と狙い方は[TABLES.md](./TABLES.md)に記載しています。

「エディターを開く」で従来の編集画面に入れます。完成台を遊んでも、未保存の編集盤面と選択状態、保存済みデータは保持されます。

## 起動

[index.html](../index.html)をブラウザで開きます。利用者によるnpmの導入やローカルサーバーの起動は不要です。PhaserをCDNから取得するため、ネット接続は必要です。localStorageの保存先はブラウザ・オリジンに依存するため、同じブラウザ・同じ場所から開いてください。

新規盤面は800×1000です。ウィンドウを変更した場合は盤面の表示を縦横同比率で拡縮し、保存座標や物理形状は変えません。小さい画面では編集パネルを下側へ配置します。

## 開発者向けテスト

package.jsonの依存はテスト用で、HTMLの実行には不要です。原稿は`src/index.template.html`、`src/media.js`、`src/tables.js`、`src/entity-model.js`、`src/entity-runtime.js`、`src/lab-tables.js`、`src/action-model.js`、`src/action-presets.js`、`src/action-runtime.js`、`src/action-tables.js`で、開発時だけPython標準ライブラリのスクリプトでindex.htmlを再生成します。

```sh
npm ci
python tools/build-game.py
npm test
npx playwright install chromium
npm run test:browser
npm run test:media
npm run test:arcade
npm run test:entities
npm run test:action
```

`npm test`は実際のPhaser図形とMatterを使用する93件の回帰テスト、`npm run test:browser`はChromiumの実画面で操作する8件です。ブラウザテストはテスト中だけ自動で静的サーバーを起動・終了し、CDNへのリクエストは同じバージョンのローカルPhaserへ差し替えます。別のChromium実行ファイルを使う環境は`PINBALL_BROWSER_EXECUTABLE`を指定できます。

`npm run test:media`は追加の6件です。HTMLだけを別フォルダへコピーして直接起動し、素材表示、物理への追従、ミュート・音量・停止、再プレイ時の後片付け、読込失敗時の継続を検証します。`npm run test:arcade`は30台の選択・遷移、3球進行、未保存データ保全、BEST保存、390px幅と左右同時タッチの5件です。`npm run test:entities`は新機能の保存・再挑戦・タッチチャージ・取消など5件です。`npm run test:action`は追加機能の画面・巨大化・出現・侵入・後片付けの4件です。合計121件です。

コードを変更したら、再生成したindex.htmlと原稿を両方コミットしてください。

オブジェクトカタログの本文は`doc/OBJECT_CATALOG.md`です。`python tools/build-object-catalog.py`で既存SVGを内包する図入りHTMLを再生成します。カタログはネット接続・Phaserなしで開けます。カタログのみの変更ではゲームの再生成は不要です。

`backup`、`backup2`、別リポジトリ`TomTomYoung/pinball2`は対象外です。
