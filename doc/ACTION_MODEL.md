# 弾種・敵・機械仕掛けの拡張仕様

更新日: 2026-10-17 JST。Entityモデルの追加仕様です。実装に先立って決定した仕様を記録します。

## 1. 敵と撃破条件

敵はDeviceにenemyとhealthを持たせた個体です。標準は弾と振っているフリッパーの両方で倒せます。hurtByでball / flipper / both / noneを指定します。弾から派生した爆風・連鎖電撃もballとして判定し、弾無効の敵を迂回して倒せません。noneは攻撃では倒せず、設定寿命で消えます。停止したフリッパーへの接触だけでは攻撃になりません。

敵種は歩兵、弾専用の装甲兵、フリッパー専用の盾兵、時間消滅する幽体、球を強打する打者、盤面を破壊する破砕兵、障害物を作る工兵、ゲームオーバーエリアへ進む突撃兵。敵種はプリセットで、撃破条件と行動は独立して組み替えられます。

敵の強打には予告と再使用時間を設けます。破壊対象は破壊可能な物体だけです。自動外周・開始球・フリッパーは盤面破壊の対象外です。工兵が出す障害物は破壊でき、寿命と生成数を制限します。出現は予告後に空いた位置へ確定し、重なりが解消しない場合は生成を取りやめます。

ゲームオーバーエリアは盤面下側の明示した矩形領域です。breach=trueの敵が進入した場合、残球や同時球数にかかわらずゲーム終了します。他の敵が落下した場合は除去だけです。敵の撃破判定を先に確定し、同じ更新で倒された敵から侵入敗北を発生させません。

## 2. 弾の巨大化と弾種

巨大化は描画と物理半径を同じ倍率で変え、位置・速度・回転・衝突設定を引き継ぎます。壁に埋まる拡大は安全な近傍へ移せる場合だけ成立させます。時限強化が終わると元の寸法へ戻り、次球で持ち越しません。捕獲中には拡大せず、解放後に扱います。

弾種は通常、強打、爆裂、電撃、貫通を用意します。強打は高ダメージと押し出し、爆裂は周辺への範囲攻撃、電撃は近くの敵への連鎖、貫通は破壊可能な敵・障害物への速度を保つ通過です。外周を貫通しません。弾種の見た目、軌跡、衝突演出を区別し、エディターと盤面の変換装置から設定できます。

## 3. 機械仕掛け

ピストンは往復のストロークと、伸び・保持・戻り・待機の4区間を持ちます。ばね台は球との接触で圧縮し、蓄えた量を解放して跳ね上げます。表示する圧縮量を物理面の位置にも反映します。固定台を中心に戻る運動と、重力で自由に落下する物体を区別します。

physics.body=dynamicを追加し、Deviceや壁にも重力・質量・衝突を与えます。編集時には物理を停止し、プレイ時だけ落下します。場外へ落ちた動的仕掛けは除去します。

## 4. 演出と互換

弾の光跡、衝突火花、爆発リング、連鎖電撃、撃破破片、出現予告、チャージ解放を描画します。演出は物理ボディを持たず、個数・持続時間を制限し、終了・再挑戦・編集復帰で破棄します。表示設定で演出を軽減できます。

既存20台と19プリセットを残します。追加機能を試すアクション台を10台追加し、合計30台とします。旧データとの互換、単一HTML起動、縦横同比率表示を維持します。既存のチャージフリッパーは押しっぱなしで溜め、離して振る仕様を継続します。

## 5. 検証

撃破可否の4通りを弾・フリッパー・爆風・電撃で検証します。侵入敗北と同時撃破、敵・物体の生成上限と出現位置、破壊対象の保護、巨大化の寸法・速度・保存非汚染・復元、ばね・ピストン・重力、弾種の実接触、入力取消、演出の寿命と後片付け、全台遷移を確認します。実装後に記法・結果を追記します。

## 6. 実装済みJSONと設定範囲

第1～5節の方針を実装しました。既存のentity.version=1 / layout.schemaVersion=2の中へ拡張しています。未知項目・未知弾種・未知生成型を拒否します。盤面座標は右が+X、下が+Y、方向は度、時間は秒、速度は座標/秒です。次の例は弾とフリッパーで倒せて、球を強打しながら侵入を狙う敵です。挙動設定JSONにはentityの中だけを入力します。

```json
{
  "type": "device", "shape": "circle", "radius": 28,
  "x": 400, "y": 330, "color": "#ff746e", "sensor": false,
  "entity": {
    "id": "counter-raider",
    "components": {
      "health": {"max": 40, "score": 500},
      "enemy": {
        "kind": "batter", "hurtBy": "both", "speed": 25,
        "sway": 20, "lifetime": 40, "behavior": "counter",
        "interval": 1.4, "strength": 1200, "breach": true
      }
    }
  }
}
```

敵の進行は初期Xを中心とした横揺れと、下向きの直線移動です。経路探索ではありません。次のゲームオーバーエリアを同じ盤面へ置くと、敵の侵入で終了します。実際の敵円と回転矩形の重なりを調べます。

```json
{
  "type": "device", "shape": "rectangle", "sensor": true,
  "x": 400, "y": 940, "width": 230, "height": 28,
  "color": "#ff3d68",
  "entity": {"id": "danger", "components": {"breachZone": {}}}
}
```

### 撃破と敵行動

- enemyは円形device専用でhealthを必須とします。kindはtrooper / armor / shield / phantom / batter / breaker / builder / raider。kindは外見、hurtByは撃破可能な攻撃で独立しています。通常敵の初期hurtByはbothです。
- hurtByはboth / ball / flipper / none。ballには通常の接触、爆風、電撃を含みます。flipperはisFlippingの時だけです。チャージ中と戻り中は攻撃になりません。通常フリッパーを上げたまま保持している間は攻撃可能です。基本ダメージは通常球10、動作中フリッパー20、満充填フリッパー60です。attack.damageの明示設定と既存の補正も使用します。
- speedは0～140（既定20）、swayは0～100（既定0）。Xは初期X＋sway×sin(年齢×2)、Yはspeedで前進します。lifetimeは1～120（既定35）。寿命での消失には得点を与えません。
- behaviorはnone / counter / demolish / build。intervalは0.5～30（既定3）。counterは接触時に下方向45～135度へ強打し、再使用時間に入ります。strengthは100～1320（既定1150）。赤い外輪が強打可能の予告で、接触後の溜め時間はありません。
- demolishは半径radius（20～400、既定150）内の最大3物体へ各20ダメージ。healthのない物体、外周、球、フリッパー、敵は対象外です。buildは左右交互に壊せる壁を予約し、自身の生成物・予約の合計4個まで。生成壁の寿命は18秒です。
- breachは真偽値で既定false。breachZoneは空の設定オブジェクトで、矩形Device＋sensor=trueが必須です。撃破と物体除去を先に確定し、残った突撃敵だけを判定します。終了理由は画面に表示します。

hurtByは攻撃ダメージの制約です。作者が明示的に記述したdestroy作用や寿命・場外除去まで禁じる指定ではありません。

### 弾強化と弾種

- projectileはball専用。kindはnormal / power / blast / spark / pierce、powerは攻撃倍率0.1～5（既定1）、cooldownは特殊効果間隔0.05～5（既定0.22）。初期の特殊弾にも弾種色を適用します。
- upgradeはkind（keepまたは上記弾種、既定keep）、scale（1～3、既定1）、duration（0.2～60、既定10）。巨大化と弾種変更は独立した期限を持ち、再取得でそれぞれ更新します。scaleは初期半径に対する倍率で、累積乗算しません。拡大時の半径上限は60です。元から60を超える球の元寸法は保持し、追加拡大は行いません。
- 巨大化の質量は初期質量×(現在半径/初期半径)²です。安全な空きがなければ拡大しません。色・弾種の変更だけは成立できます。捕獲中は変換全体を拒否します。分裂・散弾は現在の弾種と巨大化の期限を継ぎ、次球で解除します。
- powerは接触ダメージ2.6倍。動的対象を球速度の0.7倍で押し出します。blastは主接触とは別に周辺155以内の有効な耐久付き物体へ18ダメージ、動的対象へ速度500の外向き押し出し。
- sparkは主接触点から、次の有効対象まで180以内の最短距離を選び、最大4個体へ各12ダメージ。同じ対象を1連鎖で重複選択しません。ball無効の敵には伝わりません。
- pierceは接触ダメージ1.5倍。攻撃が有効な耐久付き物体との接触だけ通常反発を抑止して速度を保ちます。外周・フリッパー・通常壁・弾無効の敵では通常の衝突を残します。
- 特殊弾のフリッパー打ち返しは上向きに900～1250の速度を与えます。通常弾の既存の物理的な打ち返しを維持します。

### 出現装置と機械

- spawner.presetはenemyTrooper / enemyArmor / enemyShield / enemyPhantom / enemyBatter / enemyBreaker / enemyBuilder / enemyRaider / breakable / gravityCrate / springの11種類。出現装置自身を生成する設定は許可しません。
- intervalは0.5～60（既定5）、delayは0.25～5（既定1.2）、maxAliveは整数1～12（既定3）、totalは整数1～100（既定12）、offsetは各軸−400～400（既定[0,75]）。最初の予約は開始0.5秒後。totalは受理した予約の累計で、空き不足による取消も戻しません。
- 出現予告は予約位置に表示します。予告後、その位置と周囲最大160以内を探し、球・物体・外周と重ならない位置へ生成します。空きがなければその回を取消します。生成時は近傍へ移る場合があります。全体で生成物32・予約16を上限とし、発生源の破壊は予約を取り消します。
- pistonとspringはDeviceまたは壁に使用します。pistonはdirection（−360～360、既定−90）、stroke（1～250、既定100）、extend（0.1～5、既定0.22）、hold（0～5、既定0.2）、retract（0.1～5、既定0.7）、rest（0～10、既定1）。伸びと戻りは等速補間です。directionへ物体の初期角を加えます。
- springはdirection（既定−90）、stroke（2～80、既定28）、stiffness（10～400、既定180）、damping（1～30、既定12）、boost（100～1200、既定900）、cooldown（0.15～3、既定0.5）。接触で圧縮量=min(stroke, 8＋相対速度×0.035)、射出速度=min(1250, boost＋圧縮量×5)とします。圧縮面はx''=−stiffness×x−damping×x'で戻ります。蓄えた量はアーケード用の近似で、厳密な弾性エネルギー保存ではありません。
- physics.body=dynamicでDevice・壁が自由落下します。mass / gravityScale / frictionAirは既存設定を使います。敵・ピストン・ばねは互いに同居せず、motion / attachment / physics.body=dynamicとの併用も拒否します。重力クレートは円または矩形の通常Matter物体です。

### 追加作用と終了処理

resizeは対象球のvalueを巨大化倍率（1～3）、durationを期限として使用します。projectileは対象球のkindとdurationを設定します。spawnは対象位置にpresetを0.8秒後に生成予約し、対象が消えたら取り消します。fxは対象位置で火花を出し、valueを10～200の大きさとして使用します。作用のdurationの一般範囲は0.01～300です。自分のdestroyイベントでspawnしても発生源が消えるので生成されません。生成元を生存する別オブジェクトへ向ける必要があります。

次球では生成物・予約・弾強化・光跡・火花を解除し、配置済みの敵と物体は残存位置・耐久を引き継ぎます。再挑戦と次台は定義から作り直します。敵・動的物体は盤面下100を超えたら静かに除去します。演出は最大80件、光跡は球ごと最大16点・0.25秒、火花は0.5秒、電撃0.24秒、出現輪0.7秒。軽減時は光跡を省き、最後の12件の輪だけを描きます。

## 7. 検証結果と残る調整

実エンジンの追加36件で、4つの撃破条件、実接触の弾撃破・フリッパー撃破・貫通・強打・ばね、爆風・電撃の免疫、侵入と同時撃破、生成上限・発生源破壊・ID衝突、巨大化と質量・半径・期限・捕獲後復元・保存非汚染、重力・ピストン、10台の自然終了を確認します。全結果は[STATUS.md](./STATUS.md)に記録します。

敵の移動は直接位置制御で、障害物を避けるAIや敵同士の物理反射はありません。強化弾の数値・出現間隔・目標点は初回調整値です。高速球の連続衝突、全機能の任意合成、長時間の打感・難易度、Linux Chromium以外の実端末は引き続き調整・確認対象です。
