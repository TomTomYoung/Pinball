# Pinball 素材集 v1

2026-10-16制作。全49点（背景PNG 1、SVG 38、効果音WAV 9、BGM Ogg 1）。

`assets/index.html`をブラウザで直接開くと、盤面への配置例、全素材、衝突演出、効果音、BGMを確認できます。サーバー・npm・外部CDNは不要です。GitHubのファイル画面はHTMLを実行しないため、リポジトリを取得して開いてください。

この素材集は本体`index.html`にはまだ組み込んでいません。プレビューは素材の配置例で、プレイ可能なステージではありません。

## 制作順と内訳

1. `backgrounds/playfield.png`: 背景1点。image_genで生成。1122×1402、RGB。物体や文字を含めない暗いエナメル面。生成プロンプトは`backgrounds/PROMPT.md`。
2. `frame/`: 筐体枠2点。64×32の上辺と32×32の左上角。90度単位で回転し、辺を反復して四隅を接続。
3. `rails/`: レール3点。32×40の本体と24×40の左右端部。X方向に本体を反復して必要長さでクリップ。
4. `ball/`: ボールと影の2点。ボール64×64、影96×96。独立した透明レイヤー。
5. `flippers/`: 左右本体と支点キャップの3点。本体240×64、キャップ48×48。
6. `bumpers/`: 台座128×128、通常／点灯キャップ96×96、発光192×192の4点。
7. `effects/`: `hit-00.svg`～`hit-05.svg`の6フレーム。各128×128、1フレーム30ms、合計180ms。最後に非表示へ戻す。
8. `ui/`: スコア枠1、ボタン通常／押下／無効3、アイコン14の計18点。文字・数値はDOMで表示する。
9. `audio/sfx/`: 効果音9点。44.1kHz、16bit PCM、モノラルWAV。壁の弱／強衝突、バンパー、フリッパー上げ／戻し、落球、開始、終了、UI。
10. `audio/music/circuit-return.ogg`: オリジナル曲「Circuit Return」。112 BPM、4/4、E minor、8小節、44.1kHzステレオ。756000フレーム、17.142857秒のループ。

寸法、支点、原点、当たり判定、用途、ファイルサイズとSHA-256は[manifest.json](./manifest.json)を正本とします。`catalog.js`は同じ台帳をfile://で読めるようにした生成物です。

## 拡縮・座標の契約

全体の表示は縦横同比率です。SVGの余白も含めた画像矩形と、物理形状の寸法は区別してください。画像全体を物理寸法へ無条件に合わせると、余白分だけ球や部品が小さくなります。

- 背景の実寸は生成結果の1122×1402を保持しています。800×1000と比率がわずかに異なるため、同比率のcover（端をクリップ）またはcontain（余白）を使用します。プレビューはcoverです。
- 枠の角は固定し、直線部分を反復します。プレビューの盤面800×1000の外側に32px幅で組み立てています。下側の枠は装飾で、落球を防ぐ物理床にしません。
- レールの厚みHに対し`scale = H / 40`。端部の幅は各`24 * scale`、本体は`32 * scale`単位で反復します。全体長が端部2個未満の場合はShapeへ戻します。高さだけを引き伸ばしません。
- ボールの画像中心は(32,32)、円半径は30。物理半径Rに対して`scale = R / 30`。既定R=10なら画像表示寸法は21.333×21.333です。影は別に同倍率で配置し、既定の表示オフセットは(2,3)盤面単位です。
- フリッパーの画像内物理矩形は(20,12,200,40)。左支点は(20,32)、右は(220,32)。既定100×20ではscale=0.5、画像全体は120×32。画像の中心を支点として回転しないでください。支点キャップの中心をヒンジへ合わせます。影・支点キャップは非物理です。
- フリッパー本体は5:1の現行既定形状に対応します。幅と高さを独立編集した形状では、非等方拡大せず別途合成するか現行Shapeへ戻してください。
- バンパーキャップの中心は(48,48)、円半径は40。物理半径Rならscale=R/40。台座と発光も同倍率・同中心です。台座の外周を当たり判定に含めません。点灯は通常キャップとの差替え、発光は別レイヤーです。
- 衝突フレームは中心(64,64)。既定scale=0.5を基準に同比率で調整します。図形は一切物理に追加しません。
- UIボタン160×48・スコア枠320×96は同比率の表示を使います。任意サイズのUIはCSSで同じ色・枠を再構築し、画像を縦横別倍率で伸ばしません。アイコンは24×24、画像表示またはCSS maskで使用できます。
- SVGの色は固定値です。現在の編集色プロパティを引き継ぐ組込みでは、対応領域の色置換かShape表示を使用します。テクスチャを上書きして編集色を黙って無効にしません。

## 音の扱い

プレビューは自動再生せず、効果音・音楽の別音量、全体ミュート、全停止を備えます。タブを隠した時も停止します。既定音量は効果音0.65、音楽0.25です。

本体へ組み込む際は、最初のユーザー操作でAudioContextを開始／再開します。フリッパー音はキーリピートではなく押下／解除の状態遷移で鳴らします。同じ衝突の多重再生を抑え、同時発音数も制限してください。終了・編集復帰・シーン破棄で再生と参照を停止します。ミュートは音量だけの一時操作として扱い、物理や得点を変えません。

本体のBGMにはデコード済みAudioBufferを使用し、`loop=true`、`loopStart=0`、`loopEnd=756000/44100`とします。プレビューは直接ファイルを開くためHTML audioのloopを使用します。端末によってHTML audioのループに間隔が出る場合があり、実装時のサンプル精度ループとは区別してください。

単一HTMLを直接開く現行方式へ組み込む場合、file://からのfetchによる素材ロードを前提にしません。データURLの生成・埋込みなど、直接起動できるパッケージ方法を選び、保存往復・再プレイも再検証します。

## 制作元・再生成

背景は生成画像です。SVGは本リポジトリ用に座標・グラデーションを記述して制作しました。音は外部録音・サンプルを使わない数式合成、BGMは本素材集用の新規作曲です。外部フォントやブランド素材は同梱していません。

```sh
python tools/build-vector-assets.py
python tools/build-audio-assets.py
python tools/build-asset-catalog.py
node tools/check-assets.cjs
```

Pythonスクリプトは標準ライブラリを使用します。音声のOgg書出しにffmpeg/libvorbisが必要です。乱数seedは固定しています。音声エンコーダーの版によってOggのバイト列は変わるため、再生成後は台帳と検証結果も更新します。背景の再生成はPROMPT.mdに記載した画像生成経路を使い、元のPNGを自動で上書きしません。

検証は既存の開発用Playwrightを使用し、必要に応じて`PINBALL_BROWSER_EXECUTABLE`でChromiumを指定します。結果は[validation.json](./validation.json)です。データ形式・表示・デコード・音量ピーク・ループ境界を確認しました。聴感での音色や長時間プレイでのバランス調整は今後の実機試遊で行います。
